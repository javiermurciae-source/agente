# HTML Anything — Suite de 81 Plantillas y Generador Visual Agent-Native

> **Filosofía**: *"Markdown es el borrador. HTML es lo que leen los humanos. El agente lo escribe."*
> Provee 81 sistemas de diseño y plantillas estructuradas en HTML puro, autocontenido, sin dependencias pesadas y listas para producción editorial, ejecutiva o interactiva.

---

## 📂 Ubicación en el Sistema
- **Directorio de la Skill**: `skills/html-anything/`
- **Plantillas Maestras**: `skills/html-anything/templates/` (enlazadas en `plantillas/html-anything/`)
- Cada plantilla contiene:
  - `SKILL.md`: Instrucciones de diseño, paleta, grilla, tipografía y reglas anti-slop.
  - `example.html`: Ejemplo autocontenido y reproducible al 100%.
  - `example.md`: Estructura de contenido base.

## ⚡ Flujo de Ejecución (Ruta Quirúrgica)

1. **Selección**: Escoger la plantilla que mejor se adapte al entregable requerido.
2. **Lectura de la Plantilla**:
   - Consultar `skills/html-anything/templates/<nombre>/example.html`.
   - Extraer la estructura CSS, grilla y tipografía intactas.
3. **Inyección de Contenido**:
   - Reemplazar el texto y datos de ejemplo con el contenido real de Camilo.
   - Preservar exactamente las clases, márgenes, contraste de color y comportamiento responsive.
4. **Entrega**:
   - Guardar como archivo `.html` autocontenido en la carpeta del proyecto o `vault/`.
   - Abrir inmediatamente con `xdg-open <archivo.html>` o entregar enlace directo.
